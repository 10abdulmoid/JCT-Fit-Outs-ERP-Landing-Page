Build an Awwwards-level, scroll-driven WebGL landing page for "JCT Fit-Outs ERP", a construction fit-out ERP + CRM platform. Quality bar: GSAP + Three.js award-winning sites (cinematic, one continuous 3D story). This is NOT a template, NOT a card grid, NOT a fade-in-sections site. If anything must be cut for time, cut DOM extras, never the 3D scene or scroll choreography.

CONCEPT: "Blueprint to built." One persistent full-screen 3D scene stays fixed behind the whole page. As the user scrolls, a fit-out floor plan draws itself as glowing blueprint lines, walls rise under a scanning light, the camera flies inside a room, the building explodes into layered ERP modules, then collapses into a glowing core. All text sections are DOM overlays on top of this scene.

STACK (strict): Vite + React + TypeScript, Tailwind, gsap (ScrollTrigger, SplitText), lenis, three, @react-three/fiber, @react-three/drei, @react-three/postprocessing. Do NOT use framer-motion. No external model/HDRI files; all geometry procedural.

PRODUCT (use only this for copy; no invented features, testimonials, logos or statistics)
Web platform for interior fit-out and construction companies covering the whole lifecycle: lead capture and CRM, site visits, quantity surveying and BOQ generation, design/BOQ approval in a client portal, project scheduling (Gantt/CPM), progress validation, milestone billing, procurement and stock, subcontractor bidding (RFQ, quotes, award packs), progress claims and payment certificates with retention, variation/change-request control with client approval and re-baselining, configurable approval matrices, QuickBooks sync, project and company P&L, project close-out. Portals for Director, Project Manager, QS, Finance, Site Engineer, Client, Subcontractor and Admin. Role-based access, audit trail, dark mode.

ARCHITECTURE (strict)
- ONE persistent <Canvas> fixed full-screen behind content (pointer-events none, dpr [1,1.5]). Content scrolls above it. Page height ~700vh.
- Lenis synced to GSAP: lenis.on('scroll', ScrollTrigger.update); gsap.ticker.add(t => lenis.raf(t*1000)); gsap.ticker.lagSmoothing(0).
- A global scroll-progress store (0..1) from a scrubbed ScrollTrigger. Inside useFrame the scene lerps toward it (factor ~0.08) so motion feels weighty and never snaps. No time-based tweens for scene transitions; everything is scroll-scrubbed. Consistent easing (power3.inOut / expo.out).

SCENE
- Procedural low-poly fit-out floor plan ~12x8 units: floor slabs, thin box walls forming 6-8 rooms with doorway gaps, furniture blocks (desks, sofa, pendant lights as cylinders/spheres), using instancing.
- SIGNATURE EFFECT: each object has a build uniform uBuild (0..1) staggered by world position. At 0 it is only glowing blueprint edges (EdgesGeometry LineSegments, animated draw/dash reveal). As it rises, a bright blue scan-band sweeps upward through the object while the solid surface fades in behind it and the edges remain. Implement with custom ShaderMaterial / onBeforeCompile, not simple opacity.
- Ground blueprint grid fading with distance, ~800 floating dust particles, fog, hemisphere light + cool blue key + warm copper rim, subtle bloom and vignette.

80-100% "04 CONVERGE": layers collapse into a single glowing core (bloom), particles spiral in, camera pulls back and slowly rotates. Final headline over it: "Build the whole project in one place." with the demo CTA.

POLISH
